Sprint_6 — Автотесты для учебного сервиса Яндекс.Самокат
Описание проекта
Данный проект содержит автотесты для учебного веб-сервиса Яндекс.Самокат.
Цель — проверить функциональность сайта через UI-тестирование с использованием Selenium WebDriver, применить паттерн Page Object Model (POM) и интегрировать Allure для генерации отчётов.

Стек технологий
Python 3.x

Selenium WebDriver

Pytest

Allure Report

Page Object Model (POM)

Mozilla Firefox (браузер для запуска тестов)

Описание тестовых сценариев
Тесты раздела «Вопросы о важном»
Проверяется раскрытие текста при клике на каждый вопрос в FAQ. Для каждого вопроса написан отдельный тест.

Тесты оформления заказа
Проверяется полный позитивный сценарий оформления заказа с двумя наборами данных (параметризация).

Проверка перехода по двум точкам входа: кнопка заказа вверху и внизу страницы

Заполнение формы заказа

Проверка успешного создания заказа

Проверка перехода на главную страницу по логотипу «Самокат»

Проверка открытия главной страницы Дзена в новом окне по логотипу Яндекса

Установка и запуск
Клонировать репозиторий:

bash
Копировать
Редактировать
git clone <адрес вашего репозитория>
cd Sprint_6
Создать и активировать виртуальное окружение (пример для Windows PowerShell):

powershell
Копировать
Редактировать
python -m venv venv
.\venv\Scripts\Activate.ps1
Установить зависимости:

bash
Копировать
Редактировать
pip install -r requirements.txt
Запустить тесты с генерацией отчёта Allure:

bash
Копировать
Редактировать
pytest --alluredir=allure-results
Сгенерировать и открыть отчёт Allure:

bash
Копировать
Редактировать
allure serve allure-results
Параметризация
В проекте используется параметризация тестов через pytest.mark.parametrize для проверки разных наборов данных в оформлении заказа.
